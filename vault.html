⚙ 깃허브 보관함 연결
아직 연결되지 않았어요
  1. 깃허브에서 New repository → 이름(예: log-vault) → Private 선택 → 만들기
  2. Settings → Developer settings → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → 방금 만든 저장소 하나만
  4. Permissions → Repository permissions → Contents: Read and write
  5. 만든 토큰을 위 칸에 붙여넣고 저장 (기기마다 한 번씩)
  6. ⚠️ 토큰은 코드나 저장소 파일에 절대 넣지 마세요. 공개 저장소는 연결되지 않게 막아뒀어요
