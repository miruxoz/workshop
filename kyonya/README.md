# 쿄냐통신 (티스토리 스킨용 파일)

| 파일 | 하는 일 |
|---|---|
| `kyonya.css` | 디자인 전부 |
| `kyonya.js` | 동작 전부 (로그인·메일·채팅·뉴스·투표·BGM…) |
| `kyonya-data.js` | ✏️ 글·문구 전부 (갱신내역, 알림, 메일, 채팅 답장, 투표, BGM 목록…) |
| `preview.html` | 미리보기 (아래 버튼으로 홈/목록/글/방명록 전환) |

- 티스토리 스킨(skin.html)은 이 파일들을 `https://miruxoz.github.io/workshop/kyonya/` 에서 불러가요.
- 고치고 푸시하면 몇 분 안에 티스토리에도 반영돼요 (안 바뀌면 Ctrl+F5).
- 쿄냐뉴스 기사 제목: `[언론사] 제목` → 언론사가 오른쪽에 붙어요.
- 한마디 제목: `[쿄헤이] 내용` / `[세이] 내용` → 글쓴이가 나뉘어요.
