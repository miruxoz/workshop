📁 폰트 추가하는 방법
  1. 사이트 저장소의 fonts 폴더에 .css 파일을 만들어요 — 파일 하나 = 분류 하나 (예: 01_픽셀.css, 02_손글씨.css)
  2. 폰트 사이트에서 받은 @font-face { … } 코드를 그대로 붙여넣어요
  3. 정보를 달고 싶으면 바로 위에 주석: /* 픽셀 | 한·일·영 | 메모 */ → 종류 | 지원 글자 | 메모
  4. TTF 같은 파일은 fonts 폴더에 같이 올리고 url("파일이름.ttf") 처럼 이름만 써도 돼요
  5. 깃허브에 올린 다음 위의 🔄 를 누르면 목록에 떠요
/* 픽셀 | 한·일·영 | 12px 배수에서 선명 */
@font-face {
  font-family: "Mona12";
  src: url("https://cdn.jsdelivr.net/gh/MonadABXY/mona-font@main/web/Mona12.woff2") format("woff2");
}

⚠️ 공개 저장소라서 폰트 파일은 누구나 받을 수 있게 돼요. 웹 사용·재배포가 허용된 폰트만 올려 주세요.
