# 🔤 fonts 폴더

웹폰트 주소가 없는 폰트(TTF 등)를 여기에 넣으면, 아래 주소로 어디서든(티스토리·러브로그·사이트) 불러올 수 있어요.

```
https://cdn.jsdelivr.net/gh/깃허브아이디/저장소이름@main/fonts/파일이름.ttf
```

```css
@font-face { font-family: "내폰트"; src: url("위 주소") format("truetype"); font-display: swap; }
```

⚠️ 저장소가 공개라서 폰트 파일을 누구나 받을 수 있게 돼요. **웹 사용·재배포가 허용된 폰트인지** 꼭 확인하세요.
