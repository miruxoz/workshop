# 🎨 상태창 틀 (templates 폴더)

이 폴더에 **html 파일을 하나 넣으면** 작업대의 `🎨 상태창` 선택지에 자동으로 떠요.
(깃허브에 올린 사이트에서 🔄 를 누르면 다시 읽어요)

## 파일 모양
```html
<!-- name: 선택지에 보일 이름 -->
<div class="my-st">
  ... {{빈칸}} 을 넣은 상태창 모양 ...
</div>
<style>
  .my-st { ... }   /* 글 끝에 한 번만 붙어요 */
</style>
```

## 빈칸 목록
| 빈칸 | 내용 | 예 |
|---|---|---|
| `{{uid}}` | 상태창마다 다른 이름 (탭 라디오 버튼 name/id 에 쓰세요) | k3f9a1 |
| `{{turn}}` | 턴수 | T66 |
| `{{date}}` `{{time}}` `{{weather}}` `{{location}}` | 날짜·시간·날씨·장소 | 2014.02.03 (월) |
| `{{f.시점}}` `{{f.일정}}` `{{f.호감도}}` `{{f.타겟}}` | `라벨: 값` 칩의 값 (라벨 이름 그대로) | 레이 |
| `{{#chips}} {{icon}} {{label}} {{value}} {{text}} {{/chips}}` | 칩 전부 반복 | 📖 · 시점 · 레이 |
| `{{mission}}` | 🚩 미션 | |
| `{{#members}} {{name}} {{#tags}}{{.}}{{/tags}} {{action}} {{/members}}` | 캐릭터 카드 반복 (감정 태그는 `{{.}}`) | |
| `{{tmi}}` | 📢 캐릭터 TMI | |
| `{{#talk}} {{who}} {{say}} {{/talk}}` | 🗣️ 주변인 대사 | |
| `{{#interview}} {{q}} {{who}} {{ja}} {{ko}} {{/interview}}` | 💌 인터뷰 Q&A 반복 | |
| `{{#notes}}{{.}}{{/notes}}` | 분류 못 한 줄들 | |

- `{{#이름}} … {{/이름}}` : 목록이면 반복, 값이 있으면 한 번, **없으면 통째로 생략**
- `{{^이름}} … {{/이름}}` : 값이 **없을 때만**
- 감정 태그엔 기기 기본 이모지를 쓰려면 `font-family: 'SysEmoji', inherit;` 를 주세요 (SysEmoji 는 로그 서식에 이미 들어 있어요)
- `text-emoji` 클래스(GIF 이모지)도 그대로 쓸 수 있어요

예시: `sample-tabs.html`
